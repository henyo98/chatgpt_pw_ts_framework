STEP 2 — LOCATOR PRIORITY (STRICT ORDER)
══════════════════════════════════

Use this priority strictly (top → bottom):

1) page.getByRole(role, { name })
2) page.getByLabel()
3) page.getByPlaceholder()
4) page.getByTestId()
5) id attribute
6) stable name attribute
7) page.locator() with minimal CSS (ONLY if unavoidable)

NEVER use:
- Dynamic / hashed classes
- Framework-generated class names (unless simplified safely)
- nth-child / nth-of-type
- Deep chained CSS (>2 levels)
- XPath
- Styling-based selectors
- Long descendant chains

All selectors must:
- Be strict-mode compatible
- Be layout-independent
- Be resilient to UI changes

Prefer button locators then span/div

STEP 4 — CSS MINIMIZATION & SIMPLIFICATION RULES
══════════════════════════════════

If CSS locator is unavoidable:

GENERAL MINIMIZATION:

1. Use the SHORTEST unique selector possible.
2. Remove unnecessary:
   - Tag names
   - Redundant attributes
   - Placeholder if type is sufficient
   - Styling-related classes
3. Do NOT use "css=" prefix.
4. Maximum complexity:
   - No more than 2 levels
   - No deep descendant chains

ATTRIBUTE SIMPLIFICATION RULE:

If selector looks like:

input[type='email'][placeholder='Унесите имејл']

Try to simplify it to:

[type='email']

Prefer the most stable and minimal attribute.

CLASS SIMPLIFICATION RULE (CSS Modules / Hashed Classes):

If selector looks like:

.Login-module__0PyEKq__forgotPasswordLink

This is dynamic CSS module hashing.
SIMPLIFY IT.
Simplify it using attribute matching operators and extract meaningful stable part:
[class$='forgotPasswordLink']
[class*='forgotPassword']
[class^='Login-module']
NEVER keep:
Login-module__0PyEKq__forgotPasswordLink
Use:
- ^=  (starts with)
- $=  (ends with)
- *=  (contains)

Choose the SHORTEST stable unique version.

Examples:

❌ page.locator("input[type='email'][placeholder='Enter email']")
✅ page.locator("[type='email']")

❌ page.locator(".Login-module__0PyEKq__forgotPasswordLink")
✅ page.locator("[class$='forgotPasswordLink']")

❌ page.locator("div[class='SearchZbor123']")
✅ page.locator("[class^='SearchZbor']")

Goal:
Every CSS selector must be minimal, stable, and stripped of unnecessary text.
